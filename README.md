## Introducción a la Estadística
# La estadística es el arte de aprender a partir de los datos. Se encarga de recolectar, describrir y analizar la información para obtener conclusiones.
# Para realizar un estudio estadístico debemos preguntar:
# 1. ¿Qué quiero investigar?
# 2. ¿Dónde encuentro la información?
# 3. ¿Cómo la recojo?
# 4. ¿Qué variables me interesan?
# 5. ¿Cómo voy a analizarla?
# La estadística se utiliza en muchos campos, como **economía**, **publicidad**, **medicina**, **mercadeo**, **política**, **sector publico**, e **Internet**, para analizar situaciones y tomar decisiones.
# Se diferencia entre **población** y **muestra:**
# **Población:** Conjunto total que queremos estudiar.
# **Muestra:** Una parte de esa población que se analiza.
# Con una **muestra aleatoria** podemos obtener información para hacer inferencias sobre la población.
## Metodo rapido para memorizar
# Estadística = **recolectar** → **describir** → **analizar** → **concluir.**
## Y lo más importante
# **Población** → **Muestra** → **Datos** → **Análisis** → **Conclusiones**
